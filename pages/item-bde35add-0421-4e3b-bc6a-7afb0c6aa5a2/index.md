Rigging gives a character a skeleton you can pose. In these seven parts you'll rig a simple character in Blender from start to finish. First you'll prepare the mesh: import a base mesh, fix its scale, mirror it, and add edge loops with good edge flow so it bends cleanly at the elbows, knees, waist, shoulders and neck. Then you'll build an armature, with bones named .L and .R so Symmetrize can mirror them, and bind the mesh to it with automatic weights. Last, you'll add Inverse Kinematics (IK) constraints with pole targets to the legs and arms, and use them to pose the character sitting.

You'll need Blender and the base mesh FBX file from the exercise. The videos use Blender 2.90, so some menus and panels look different in newer versions; in Blender 4.0 and later, bone layers were replaced by bone collections.
