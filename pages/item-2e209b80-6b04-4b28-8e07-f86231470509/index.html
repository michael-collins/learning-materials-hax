In this exercise, you will practice modeling a character in a T-pose and rendering using an NPR workflow.

Learning Objectives

  1. Become familiarized with the NPR workflow.
  2. Learn the character modeling workflow

Instructions

  1. Model a polygonal character in the T pose. Choose a theme for the character (IE - fantasy, sci-fi, etc.).
  2. Watch the tutorials.
  3. Create greasepencil modifier, shaders, materials, and freestyle lines to create a manga or comic book visual style.
  4. Save a 1920x1080 render as LASTNAME-npr-character.png in the project folder.
  5. Save your file as LASTNAME-npr-character.blend in the project folder.
  6. Compress the project folder once you’ve completed the tutorial and rename it LASTNAME-npr-character.zip.
  7. Upload the .zip file to the assignment dropbox.
  8. Double check that you’ve included all files and that your .zip file can be downloaded and opened.
