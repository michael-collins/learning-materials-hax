This pathway prepares students for careers in the game industry, focusing on the creation of 3D content for interactive and real-time applications. Students will learn to balance artistic quality with technical performance requirements, creating assets that work seamlessly in game engines and virtual reality platforms.

Who This Is For

This pathway is perfect for students interested in:

  • Video game development
  • Virtual reality experiences
  • Augmented reality applications
  • Interactive installations
  • Mobile game development

Career Outcomes

Graduates will be prepared for roles including:

  • 3D Game Artist
  • Environment Artist
  • Character Artist
  • Technical Artist
  • VR/AR Developer
  • Props Artist

Check your readiness

What makes a 3D asset game-ready?

Efficient topology within its polygon budget, clean UVs with consistent texel density, baked and PBR textures, levels of detail, correct scale and pivot, collision, and clear naming.

Name two technical limits you have to design within for a real-time game.

For example: the frame-time budget, polygon counts, draw calls, texture memory and the cost of dynamic lights and shadows.
