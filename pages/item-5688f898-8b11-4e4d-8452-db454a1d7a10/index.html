In this part you'll put a PlayCanvas scene online as a website anyone can open from a link, using GitHub Pages, which hosts what's in a GitHub repository as a static website. The video downloads a build of the scene from PlayCanvas, uploads its files to a new GitHub repository, turns on GitHub Pages, adds the .nojekyll file the scene's scripts need, and tests the live scene.   1. Choose what to publish. 2:52 Open the repository's Settings (the video opens them in a new tab while the commit finishes 2:59) and choose Pages 3:05.   2. Add a .nojekyll file. 3:41 Back on the Code tab, choose Add file → Create new file 3:48. Name it .nojekyll, with the dot at the start, and commit it; it can stay empty 3:54.
