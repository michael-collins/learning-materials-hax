In this exercise, you will create a final render of the KEM Weber Airline Chair. You will practice setting up 3-point lighting, adding cameras, creating a backdrop, optionally adding additional textures to the materials, configuring render settings, and doing some post-production cleanup in Photoshop.

Learning Objectives

  1. Become familiarized with the rendering process.
  2. Become familiarized with setting up and configuring lights and a backdrop.
  3. Practice color grading in Photoshop

Instructions

Note: You should have a basic understanding of Blender's interface before completing this exercise. You should also complete the exercise called Modeling the Airline Chair prior to completing this exercise.

  1. Duplicate the texturing folder on your computer. This will be your project folder. Save all files to this folder.
  2. Follow the video demonstrations to light and render the KEM Weber Airline Chair.
  3. Enable Cycles rendering mode.
  4. Add a backdrop and three point lighting setup.
  5. Configure your render camera with a pleasing focal length and compose your layout.
  6. Configure the render settings sampling to be high enough to reduce noise. Somewhere between 250 and 750 should give good results.
  7. Render and import the image into Photoshop to adjust saturation, contrast.
  8. Save the render as LASTNAME-rendering-chair.png, etc. in the project folder. Name the files in an organized in a logical way.
  9. Remove large Photoshop files that you may have in the project folder before compressing for upload.
  10. Save the 3D scene file as LASTNAME-rendering-chair in the project folder.
  11. Compress the project folder once you’ve completed the tutorial and rename it LASTNAME-rendering-chair.zip.
  12. Upload the .zip file to the assignment dropbox.
  13. Double check that you’ve included all files and that your .zip file can be downloaded and opened.
